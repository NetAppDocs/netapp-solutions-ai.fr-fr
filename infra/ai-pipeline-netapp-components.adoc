[[4-1-netapp-xcp-core-value]]
== 4.1 NetApp XCP — Valeur fondamentale

XCP est la couche de mobilité qui dissocie l'emplacement des données de l'emplacement de calcul. Un simple paramètre de configuration (`xcp++_++copy++_++destination`) détermine si les données préparées et les artefacts de modèle sont stockés dans NetApp ONTAP S3 ou dans un niveau haute performance LustreFS, avec  `model++_++training`, `fine++_++tuning`, et  `inferencing` qui lisent et écrivent automatiquement depuis et vers la même destination.
